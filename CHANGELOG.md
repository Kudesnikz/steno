# 🚀 Что нового (Changelog)

Обзор изменений между версиями (от `5bef6aae` до `cb89d745`). За это время была проделана огромная работа по рефакторингу приложения, улучшению поддержки macOS, полному обновлению пользовательского интерфейса и доработке взаимодействия с ИИ.

### 🍏 Поддержка macOS и сборка
* **Multi-arch поддержка**: Добавлена полноценная поддержка сборки для обеих архитектур — **Apple Silicon (arm64)** и **Intel (x86_64)**.
* **Apple Code Signing**: Настроена подпись кода с использованием сертификатов Apple Developer. Добавлены настройки прав (entitlements) и Hardened Runtime для прохождения проверок безопасности macOS (Gatekeeper).
* **Улучшенные DMG-образы**: Процесс упаковки DMG стал надежнее. В образ добавлены понятные инструкции по установке приложения.
* **Архитектурно-зависимый FFmpeg**: Теперь приложение автоматически использует правильный бинарник `ffmpeg` в зависимости от того, на каком процессоре (M1/M2/M3 или Intel) оно запущено.
* **Фикс фреймворков**: Добавлен специальный скрипт (`fix_frameworks.py`), который автоматически приводит структуру внутри `.app` к строгим стандартам Apple для успешной подписи.

### 🎨 Пользовательский интерфейс (UI / UX)
* **Переход на PyQt6**: Полный перенос и рефакторинг интерфейса на современный фреймворк PyQt6.
* **Новые компоненты и экраны**: Код интерфейса логически разбит на модули (главное окно, плеер, настройки, онбординг для новых пользователей).
* **Системные окна macOS**: Убраны устаревшие "хаки" для безрамочных окон. Теперь приложение использует стандартное управление окнами, что делает его более стабильным и привычным для пользователей Mac.
* **Детализация сессий**: В списке сессий теперь отображается **размер файла**.
* **Статистика токенов**: На главной панели добавлен удобный счетчик использованных токенов ИИ (показывает значения *Total* и *Last*).
* **Интеграция с системным треем**: Улучшена работа иконки в строке меню (добавлена нативная интеграция с AppKit через декораторы `@objc.IBAction`).

### 🧠 Искусственный интеллект (GenAI)
* **Обновление Google GenAI SDK**: Исправлена работа с URL, улучшен маппинг файлов (`types.Part.from_uri`) и проверка состояний.
* **Новые модели и промпты**: Обновлена конфигурация ИИ-моделей (интеграция свежих версий Gemini) и улучшены системные Markdown-промпты для более качественной обработки текста.

### ⚙️ Внутренняя архитектура и стабильность
* **Глубокий рефакторинг**: Структура проекта приведена в порядок. Логика разделена по папкам: `app/core/` (ядро), `app/ui/` (интерфейс) и `scripts/` (скрипты сборки).
* **Стабильная запись аудио**: Обновлен механизм записи — теперь используются потокобезопасные сигналы для передачи данных в интерфейс без зависаний.
* **Исправление багов**: Решена критическая проблема с правами доступа после переустановки приложения.
* **Автоматизация**: Добавлены shell-скрипты для очистки (`clean.sh`) и сборки, а также базовые тестовые файлы (`test_genai.py`, `test_mac_ui.py`).
